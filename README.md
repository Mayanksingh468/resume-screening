# Resume Screening System using NLP

## Overview

The Resume Screening System is an AI-powered application designed to streamline the recruitment process by automatically evaluating resumes against job descriptions. The system leverages Natural Language Processing (NLP) and Machine Learning techniques to analyze candidate profiles, identify relevant skills, and generate matching scores that help recruiters make informed hiring decisions.

This project demonstrates the practical application of NLP, information retrieval, and machine learning in solving real-world recruitment challenges.

---

## Key Features

* Automated resume parsing and analysis
* Skill and keyword extraction from resumes
* Job description matching using NLP techniques
* Resume ranking based on relevance scores
* Identification of missing skills and qualifications
* Interactive dashboard for recruiters
* REST API integration between frontend and backend

---

## How It Works

1. Upload candidate resumes.
2. Input the job description.
3. Perform text preprocessing and cleaning.
4. Extract relevant features from resumes and job descriptions.
5. Apply TF-IDF vectorization to convert text into numerical representations.
6. Calculate similarity scores using cosine similarity.
7. Rank candidates based on relevance to the job requirements.
8. Display results through an interactive dashboard.
